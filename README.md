A faster drop-in for makefun-site 1.0.0: it builds the same static sites byte for byte, in about a third of the CPU time. `solve.js` re-implements makefun-site's own front matter, template dialect, Markdown subset, slug rule and report with less waste — chunked inline escaping, a fused Markdown lexer/renderer, cached slugs, resolved-link caching, and templates compiled to JavaScript functions — and `main.ts` drives it over `/input/cases.json` to `/output/answers.json`.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
